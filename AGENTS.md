# Worker entry point

1. Read `STATUS.md` and `specs/SIREN_V0_1.md` before changing code.
2. Follow the copied Forge constitution and standards.
3. Keep the application local-first and permissions narrowly scoped.
4. Do not commit credentials, model binaries, caches, installers, or user data.
5. Run `powershell -ExecutionPolicy Bypass -File scripts/validate.ps1` and record evidence in `STATUS.md`.
6. Publication and release tagging require the explicit release gate in the handoff.

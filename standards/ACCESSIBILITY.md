# Accessibility standard

- Use semantic HTML and native controls before custom widgets.
- Every function works by keyboard; focus is visible and never removed without an equivalent replacement.
- Controls have programmatic names, states, and errors. Decorative content is hidden from assistive technology.
- Support zoom, text reflow, reduced motion, light/dark/system themes, and sufficient WCAG AA contrast.
- Do not encode meaning only by color. Test the primary flow with keyboard and an accessibility tree or equivalent semantic inspection.
- Accessibility failures block release unless the owner explicitly accepts a documented limitation without weakening an existing control.
